ZERO INSTALL Method 1 — Microsoft Edge Print to PDF
When to use: PDFsam isn't installed yet and you need to send a guest their PDF right now. Uses only software already on Windows — no download required.
Privacy: Nothing leaves your computer. Microsoft Edge renders the PDF locally.
  • Open the eDoc in Microsoft Edge
    Right-click the group eDoc PDF → Open with → Microsoft Edge.
  • Find the page range for your guest
    From PDFsam_Split_Points.txt (in your downloaded kit) or the desk card: guest 01 = pages 3–5, guest 02 = pages 6–8, and so on in steps of 3.
  • Print to PDF — one guest at a time
    Ctrl+P → Printer: Microsoft Print to PDF → Pages: 3-5 → Print → save as 01_SEEMANTHINI_PORURI.pdf. Repeat for each of the 21 guests.
    Takes ~1 min per guest. Switch to Method 2 (PDFsam) once installed — far faster for the full batch.
  • Open Excel tracker + send
    Open Raj_eDoc_Guest_Tracker.csv in Excel. Fill in guest email (column F), mark Sent = Y (column G) after each send.
RAJ · DEFAULT Method 2 — PDFsam Desktop Kit + Excel Tracker
Privacy: Fully offline. PDFsam runs on your PC and never uploads anything. Best choice for guest names and confirmation numbers.
In your downloaded kit:
OPEN_DESK_KIT.bat · Raj_eDoc_Guest_Tracker.csv · Raj_eDoc_Desk_Card.html · Gmail_Itinerary_Email.txt · PDFsam_Split_Points.txt
  • Install PDFsam Basic (one time)
    Download free from pdfsam.org. No account needed.
  • Trim the group cover + appendix pages
    PDFsam → Organize → open eDoc → delete pages 1-2 and 66-93 → save as Guests_Only.pdf.
  • Split every 3 pages → 21 files
    PDFsam → Split → upload Guests_Only.pdf → choose Split every 3 pages → go. You get split_1.pdf through split_21.pdf.
  • Rename using the Excel tracker
    Open Raj_eDoc_Guest_Tracker.csv in Excel. Column D shows the target filename for each numbered file. Verify the ALL CAPS name on each PDF matches.
    Print Raj_eDoc_Desk_Card.html (khadwedsmadd.netlify.app/edoc/desk) and keep it beside your monitor as a quick rename map.
  • Send from Gmail · mark Sent = Y
    Copy body from Gmail_Itinerary_Email.txt. Attach one guest PDF only. Mark Sent = Y in column G after each send.

Security checklist (every batch)

  • Send one guest PDF per email. Never forward the full 93-page group eDoc to anyone.
  • Open each PDF before sending. Confirm the ALL CAPS name on page 1 matches the recipient's address.
  • Track every send in the Excel tracker (Sent = Y, column G) — no skips, no duplicates.
  • Prefer offline Methods 1–4. Use Method 5 (web) only when everything else fails.

Common questions

Can Jean split the file and send me the output folder?
Yes. Jean runs Method 3 or 4 and shares the split_output folder (via Google Drive or USB). Raj handles Gmail sends and Excel tracking.
Guest page count isn't 3 on a new eDoc — what do I do?
Use Method 3 (PowerShell) or Method 4 (Python). Both detect guest boundaries from text, not page count, so they handle layout variations automatically.
It says "PDF tools not installed" on a new computer
The kit ships with the tool inside tools\poppler\bin\. If a fresh PC is missing it, press Y when the script offers to install automatically (~30 sec), or run INSTALL_POPPLER.bat once. No website browsing needed.
"pip is not recognized" for the Python setup
Reinstall Python from python.org — check Add Python to PATH. Alternatively, use Method 3 (PowerShell) — no Python required.
I sent the wrong PDF to a guest
Send a follow-up with the correct PDF and a brief apology. Mark the correction in the Notes column of the Excel tracker.
