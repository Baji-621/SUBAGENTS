eDoc PDF Splitter — Process Guide

How to split any new Air Transat group eDoc into individual guest PDFs and send them

Owner: Raj / Jean · Absolute Wedsite Last updated: May 2026 Kit download: Google Drive Online guide: khadwedsmadd.netlify.app/edoc

Purpose

Air Transat sends one large PDF (called an "eDoc") that contains itinerary pages for every guest in a group booking. This document explains — step by step — how to split that single PDF into one file per guest and email each guest only their own pages. No guest should ever receive the full group eDoc.

Result of this process: 21 guest PDFs (one per person) + one shared reference PDF (baggage, hotel, e-ticket) + a send-tracking spreadsheet. Each guest PDF is named after the passenger, e.g. 01_SEEMANTHINI_PORURI.pdf.

What Air Transat sends you — understanding the eDoc structure

Before splitting, understand what's in the file. Standard Air Transat group eDocs follow this layout:

PAGE 1-2 Group booking cover (agency reference only — do NOT send to guests) PAGE 3-5 Guest 1 itinerary (3 pages: itinerary + flight info x2) PAGE 6-8 Guest 2 itinerary PAGE 9-11 Guest 3 itinerary ... (pattern repeats: 3 pages per guest) PAGE 63-65 Guest 21 itinerary (last guest) PAGE 66-93 Shared appendix: baggage dimensions, hotel details, e-ticket reference (optional — you can attach this to everyone's email)
How to check your specific eDoc's layout: Open the PDF in Microsoft Edge or Adobe Acrobat. Look at page 3 — the first line in ALL CAPS is the first guest's name. Every 3 pages you should see a new name. The appendix starts when you see "Baggage dimensions" or "ELECTRONIC TICKET." If the page count per guest is different, use an auto-detect method (Steps 5A or 5B below) — they handle any layout automatically.
Note for non-standard eDocs: Occasionally Air Transat includes an extra information page, making some guests 4 pages instead of 3. The auto-detect methods (split_edoc.py, split_edoc_markers.py, 3_SPLIT_WITH_MARKERS.bat) handle this correctly. The fixed-page method (PDFsam "every 3 pages" or split_edoc_fixedpage.py) will fail in this case.

Detailed Steps

1
Receive and save the new eDoc PDF
Who: Raj
  1. Open the email from Air Transat (subject usually contains "e-Document" or "eDoc").
  2. Download the PDF attachment. The filename doesn't matter — the scripts find any PDF in the folder automatically.
  3. Copy or move the PDF file into the kit folder:
    On your PC: eDoc PDF Splitter\ (wherever you saved the kit from Google Drive)
    The kit folder is the same folder that contains 1_SPLIT_MY_EDOC.bat, 3_SPLIT_WITH_MARKERS.bat, etc.
If you have multiple PDFs in the folder, the script will ask you to pick one by number — that's normal.
✓ Output: eDoc PDF is sitting in the kit folder alongside the scripts.
2
Identify the eDoc structure (30 seconds)
Who: Raj

Open the PDF in Microsoft Edge (right-click → Open with → Microsoft Edge) and quickly note:

  1. Total pages — shown at the bottom of Edge (e.g. "Page 1 of 93").
  2. First guest name — jump to page 3. The passenger name appears in ALL CAPS near the top. This confirms the layout is standard.
  3. Guest count — can be calculated: (total pages − 2 cover pages − appendix pages) ÷ 3. For our sample: (93 − 2 − 28) ÷ 3 = 21 guests.
  4. Where appendix starts — scroll forward until you see "Baggage dimensions" (first appendix page). Note that page number.
Shortcut: If you're using an auto-detect method (A, B, or C), skip this step entirely — the script figures out the structure automatically by reading the text on each page.
Only needed if you're doing Method D (PDFsam manual) — you need exact page numbers to trim correctly.
✓ Output: You know total pages, guest count, and appendix start page.
3A
Split — Method A: Python auto-detect (primary, fastest)
Who: Jean or Raj · requires Python
First time only: double-click 2_SETUP_ONCE.bat — it walks you through Python + library install (~5 min). After that you only ever double-click 1_SPLIT_MY_EDOC.bat.
  1. Make sure the eDoc PDF is in the kit folder (Step 1).
  2. Double-click 1_SPLIT_MY_EDOC.bat. A black window opens.
  3. The script lists every passenger it found with page ranges. Read the list and confirm the names look correct.
  4. Press Y then Enter (or just Enter) to split.
  5. A Windows Explorer window opens showing the output folder — split_output\.
Expected output: 21 guest PDFs + 00_Group_Travel_Reference.pdf + manifest.json + Raj_eDoc_Guest_Tracker.csv
If the script says "No passenger itineraries found" — check that the PDF is an Air Transat eDoc (not a different airline). See Troubleshooting section.
✓ Output: split_output\ folder with all guest PDFs ready to send.
3B
Split — Method B: Lightweight Python (pypdf, no PyMuPDF needed)
Who: Jean or Raj · Python must be installed
When to use: pip install pymupdf failed or took too long. This method uses a smaller library (~1 MB vs 50 MB).
  1. Open Command Prompt (press Win + R, type cmd, press Enter).
  2. Install the library (one time only):
    pip install pypdf
  3. Navigate to the kit folder:
    cd "C:\path\to\eDoc PDF Splitter"
  4. Run the script:
    python split_edoc_markers.py
  5. Review the passenger list → press Enter to split.
✓ Output: same as Method A — 21 guest PDFs in split_output\.
3C
Split — Method C: PowerShell + Poppler (no Python, double-click)
Who: Jean · no Python needed
Zero setup on Drive kit: Poppler is pre-bundled. Just drop the PDF and double-click — nothing to install.
  1. Make sure the eDoc PDF is in the kit folder (Step 1).
  2. Double-click 3_SPLIT_WITH_MARKERS.bat.
  3. First time on a new PC (if Poppler is not bundled): a yellow box appears offering to download tools automatically. Press Y + Enter. Takes ~30 seconds.
  4. The script lists every passenger. Check the names, then press Y + Enter.
  5. The split_output\ folder opens automatically when done.
✓ Output: 21 guest PDFs in split_output\.
3D
Split — Method D: PDFsam manual (standard-layout eDocs only)
Who: Raj · PDFsam must be installed · pdfsam.org (free)
Only works reliably when every guest has exactly 3 pages. If any guest has a different page count, use Method A or C instead — you'll get wrong names on PDFs.

Part 1 — Trim the cover and appendix pages:

  1. Open PDFsam → Organize.
  2. Open the group eDoc PDF.
  3. Delete pages 1–2 (group cover) and pages [appendix start]–[end]. For a 93-page eDoc with appendix from page 66: delete pages 1–2 and 66–93.
  4. Save as Guests_Only.pdf. It should contain exactly 63 pages (21 guests × 3 pages).

Part 2 — Split into guest files:

  1. PDFsam → Split.
  2. Open Guests_Only.pdf.
  3. Choose "Split every 3 pages".
  4. Click Run. You get split_1.pdf through split_21.pdf.

Part 3 — Rename the files:

  1. Open PDFsam_Split_Points.txt in the kit folder — it has the exact rename map for this booking.
  2. Rename each file: split_1.pdf → 01_SEEMANTHINI_PORURI.pdf, etc.
  3. For a completely new booking (different guest names): open one of the auto-detect methods first to get the correct names, then rename manually. See "New booking with different guests" in Exceptions below.
✓ Output: 21 renamed PDFs ready to send.
4
Verify the output (2 minutes — do not skip)
Who: Raj
Never skip verification. Sending the wrong PDF to a guest exposes another person's name, confirmation number, and travel dates. One minute of checking prevents a serious privacy error.
  1. Count the files. In the split_output\ folder: should be 21 guest PDFs + 1 reference PDF = 22 files total. (Plus manifest.json and CSV.)
  2. Spot-check 3 PDFs. Open guest #01, #11, and #21. On page 1 of each, confirm the ALL CAPS passenger name matches the filename. Example: 01_SEEMANTHINI_PORURI.pdf should show "SEEMANTHINI PORURI" on the first page.
  3. Check page count. Each guest PDF should be 3 pages (check the page counter at the bottom of Edge/Acrobat). The reference PDF will be ~28 pages.
  4. Check the CSV. Open split_output\Raj_eDoc_Guest_Tracker.csv in Excel. Confirm 21 guest rows plus 1 REF row.
If anything looks wrong — STOP. Do not send any emails until the split is correct. Delete the split_output\ folder and re-run the splitter. If the problem persists, use a different method (A, B, or C) which auto-detect page boundaries.
✓ Output: Verified set of 21 guest PDFs, ready to email.
5
Fill in guest emails in the tracker spreadsheet
Who: Raj
  1. Open split_output\Raj_eDoc_Guest_Tracker.csv in Excel. (Or open Raj_eDoc_Guest_Tracker.csv in the kit folder — it has the same guest list.)
  2. Column A = guest number, B = full name, C = page range, D = filename, E = confirmation code.
  3. Fill in Column F (Guest Email) for each of the 21 guests. Cross-reference your booking system or group email list.
  4. Save the file.
You don't need to fill in all 21 emails before starting to send. You can fill in a few, send those, then continue. Just track as you go.
✓ Output: Tracker has email addresses for all guests.
6
Email each guest their individual PDF
Who: Raj
  1. Open Gmail_Itinerary_Email.txt in the kit folder. Copy the email body.
  2. In Gmail: click Compose. Paste the email body. Replace [Guest first name] with the guest's actual first name.
  3. Set the To: field to the guest's email (from your tracker, Column F).
  4. Click the attachment button (paperclip icon). Attach ONLY the one PDF for that guest from split_output\. For example: 01_SEEMANTHINI_PORURI.pdf.
  5. Before hitting Send — do this 10-second check:
    • Open the attached PDF. Does the ALL CAPS name on page 1 match the person you're sending to?
    • Is only one PDF attached? (Not the full 93-page group eDoc.)
  6. Send.
  7. In the tracker, find that guest's row → Column G → type Y. Save.
  8. Repeat for each guest.
Optional: Attach 00_Group_Travel_Reference.pdf as a second attachment for guests who want the baggage rules, hotel coordinates, and e-ticket reference pages.
✓ Output: All 21 guests emailed. All rows in tracker show Sent = Y.

Exceptions and Edge Cases

SituationWhat to do
New booking — completely different guest names Methods A, B, C auto-detect names from the PDF text — no changes needed, just drop the PDF and run.
Method D (PDFsam): rename files manually; use the auto-detect preview first to get the correct order and names. Run 1_SPLIT_MY_EDOC.bat with "Preview" to print the name list.
Method B fixed-page (split_edoc_fixedpage.py): update the DEFAULT_NAMES list at the top of the script before running.
Some guests have 4 pages instead of 3 Use Method A (split_edoc.py), B (split_edoc_markers.py), or C (3_SPLIT_WITH_MARKERS.bat). All three auto-detect boundaries and handle variable page counts.
Do NOT use PDFsam "every 3 pages" or split_edoc_fixedpage.py — these will split at the wrong boundary.
"No passenger itineraries found" error The PDF may not have a text layer (scanned image only). Try opening it in Edge — if you can't select/copy text, the eDoc is a scan. Request a new copy from Air Transat with a proper text layer.
Also check: is the flight actually TS 326 / TS 327? Scripts look for these codes. For different Air Transat routes, confirm the flight numbers in the PDF match the script's expectations.
Script detects fewer than expected guests (e.g. 19 of 21) Run with -PreviewOnly flag (Method C) or check the manifest.json to see which names were missed. The missing guest may have a name that's only one ALL-CAPS word (unusual but possible). Contact Absolute Wedsite team to add that name to the script's detection logic.
"PDF tools not installed" on a new PC Method C: press Y when the script offers to install — or run INSTALL_POPPLER.bat once. If internet is restricted, copy the tools\poppler\bin\ folder from the Drive kit.
Python says "pip is not recognized" Reinstall Python from python.org and check Add Python to PATH during setup. Then re-run 2_SETUP_ONCE.bat. Or switch to Method C (no Python needed).
Wrong guest PDF was sent to the wrong person Send a follow-up email immediately with the correct PDF and a brief apology ("Please disregard the previous email — the correct itinerary is attached below"). If the wrong file exposed another guest's confirmation number, notify both guests. Mark both rows in the tracker (wrong send and correct resend) with notes in Column I.
Air Transat resends a corrected eDoc Start the process over from Step 1. Delete the old split_output\ folder first (or rename it to split_output_OLD\). Re-run the split on the new PDF. Resend only to guests whose information changed — check the new manifest.json against the old one.
Guest says their confirmation number is wrong Open their PDF and check the 6-character code on page 1. If it doesn't match the booking system, contact Air Transat directly — the error is in the source eDoc, not the split. Do not resend — the PDF you sent is exactly what Air Transat provided.

Pre-send checklist (run this before every batch)

  • eDoc PDF was received directly from Air Transat — not forwarded or edited
  • Script detected the expected number of guests (check manifest.json)
  • Opened and verified at least 3 guest PDFs (first, middle, last)
  • Each spot-checked PDF: ALL CAPS name on page 1 matches the filename
  • Each guest PDF is 3 pages (or expected page count)
  • 00_Group_Travel_Reference.pdf exists and opens correctly
  • Guest tracker CSV has all email addresses filled in before sending
  • Each Gmail attachment is ONE guest PDF only — not the full eDoc
  • After each send: Sent = Y marked in tracker Column G
