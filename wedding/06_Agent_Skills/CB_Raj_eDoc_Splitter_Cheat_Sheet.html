Split Air Transat eDoc · 3 Steps · ~8 Minutes

AbsoluteWed · Raj · Bookmark: ilovepdf.com/split_pdf

Step 1 · Trim to guest pages (2 min)

  1. Open ilovepdf.com/organize-pdf
  2. Upload the group eDoc PDF.
  3. Select pages 3 through 65 only. Delete pages 1-2 and 66-end.
  4. Download as Guests_Only.pdf.

Step 2 · Split every 3 pages (1 min)

  1. Open ilovepdf.com/split_pdf
  2. Upload Guests_Only.pdf.
  3. Choose Split every 3 pages.
  4. Download the ZIP (21 files).

Step 3 · Rename and send (5 min)

  1. Unzip. You will get 21 PDFs in order.
  2. Rename file 1 → 01_SEEMANTHINI_PORURI.pdf, file 2 → 02_YASODHARA_KANCHERLA.pdf, and so on (table below).
  3. Email each guest only their file. Double-check the name on page 1 before sending.

Before you send · 10-second check

  1. Guest name on PDF matches email recipient.
  2. Booking number matches group file (sample: 75953181).
  3. Never forward the full 93-page eDoc to one guest.
  4. Optional: attach Group_Travel_Reference.pdf (pages 66-93) to everyone.

Pattern for new eDocs: pages 1-2 = group cover · each guest = 3 pages · last pages = shared travel reference. Find the next guest by the name in ALL CAPS above the flight (TS 326 / TS 327).
